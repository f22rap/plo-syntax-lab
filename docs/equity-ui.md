# EQ入力画面・結果表：ステップ3

> この文書は当該ステップの記録。現在の画面では集計タブへ統合し、自分のレンジを全入力CSVの合計に固定。現行操作は [equity-integrated-ui.md](equity-integrated-ui.md)、保存機能は [equity-save.md](equity-save.md) を参照。

ステップ2のアクション前EQエンジンを、Windows EXEの新しい「EQ」タブへ接続した。グラフと結果保存・履歴は後続段階。GitHubへは未プッシュ。

## 操作

1. 「集計」タブでボードとsyntax条件を選択する。生成画面から取り込んだ条件・デフォルト条件を利用できる。「全ハンド」チェックもEQの条件に含む。
2. 「EQ」タブを開く。ボード・条件・選択中のアクションCSVの個数を表示する。
3. 自分のアクション前レンジを選ぶ。
   - 全ハンドを均等に扱う：ボードに対する合法ハンドのうち、各syntaxに一致する集合。
   - アクション前レンジを入力：テキストまたは専用レンジCSVを入力し、各syntaxで抽出。
   - 全アクションCSVを合計：集計タブの2〜3CSVを使い、同じハンドのweightを合計。全アクション・共通weight基準であることの確認チェックが必要。
4. 相手のアクション前レンジを、テキストまたはレンジCSVで入力する。
5. syntaxごとの試行数・任意のシード・リバー全列挙・全列挙上限を設定し、「EQを計算」を押す。
6. 条件別のEQ、95%区間、計算方式、有効コンボ数、処理数、計算秒、状態を結果表に表示する。マウスを合わせると勝敗・シード・除外数も確認できる。

フロップ・ターンは常にモンテカルロ。リバー全列挙の既定上限は候補対戦組5,000,000。上限超過は条件ごとの理由として表示し、自動でモンテカルロへ変更しない。利用者が全列挙チェックを外して再計算する。

自分のレンジに該当ハンドがないsyntaxや、合法な対戦組がない条件は、理由を表示してEQを空欄にする。他の条件の計算は続行する。同じsyntaxが別のラベルで重複している場合は計算を共有する。条件の並びを変えても再現できるよう、各syntaxのシードは基準シードとsyntaxから生成する。

## レンジCSV

専用レンジCSVは添付仕様の入力形式を使用する。これは、既存のアクション比較CSVとは別の入力経路。

- 20MiB以下。UTF-8の厳密デコード、失敗時はShift_JIS。BOM、CR/LF/CRLF、引用符とエスケープに対応。
- hand/combo/range/ハンド/コンボ/レンジ、weight/frequency/freq/重み/頻度の列見出しに対応。列順は自由。`weight`／重みがある場合は優先し、ない場合のみ`frequency`／`freq`／頻度を使用する。ソルバーの7列形式にも対応し、percent・ev・ev_diff・variationsは重みに使用しない。
- 見出しなしは手札・任意の重みの1〜2列。曖昧な列数変更はエラー。
- 重みは0〜1または0〜100を選択。%表記は選択に関係なく百分率。空欄は1。
- weight 0の行もハンドを検証した上で除外。除外行、ハンドセル内の複数条件・@・改行は未対応として拒否。
- 全行の検証に成功した時だけ編集欄を置き換える。読み込み中止・エラー時は元の入力を保持する。計算は自動開始しない。

全アクションCSVの経路は従来の比較入力の規則を維持する。UTF-8、具体的4枚、hand/comboとweight列、weight 0〜1。同一ファイルの重複、同一ハンドの重複、ボード衝突、ファイル名に含まれるボードの不一致を拒否。frequency列では代用しない。CSVごとに独立して正規化したレンジから元レンジを推測しない。

## 状態と既存機能

- 入力・条件をスナップショットにしてバックグラウンドで計算する。入力ファイルの外部変更を自動監視しないため、変更時は再計算する。
- 計算中は入力と再実行を無効化し、中止を有効化。通常のCSV比較とEQを同時に実行しない。
- ボード・条件・レンジ・設定の変更で確定結果を無効化する。進行中の計算があれば中止し、世代番号で遅れて届いた進捗・結果を破棄する。
- 計算中の生成条件追加は拒否する。EXE終了時は処理を中止してから閉じる。
- 中止結果は確定EQとして保持しない。進捗表示には「途中EQ」と明記する。
- 既存の集計・履歴タブの位置、CSV比較、PowerShell実行、syntax生成は維持する。
