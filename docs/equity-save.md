# EQの保存・履歴・確認用EXE（ステップ5）

## 追加した機能

- EQタブにCSV保存、JSON保存、グラフSVG保存、EQ履歴ボタンを追加。
- 確定EQを含む計算が完了すると、専用履歴へ自動保存する。保存に失敗しても計算結果を保持し、手動保存を利用できる。
- 入力変更後、計算中、中止後、確定EQがない場合は保存不可。グラフの点がない場合はSVG保存不可。
- 自分／相手の読み込み元レンジCSV、アクションCSV、アプリEXEへの上書きを拒否。書き出しは一時ファイルからの置き換えで行う。

## 保存形式

| 形式 | 内容 |
| --- | --- |
| CSV | UTF-8 BOM付き。syntax × アクションを1行とし、EQ、95%区間、頻度、全列挙／試行計算、処理件数、シード、コンボ数、合法対戦組数、エラー理由を保存。該当なしは空欄。ラベル内の引用符・改行を保持し、表計算ソフトの数式になる先頭文字はエスケープ。 |
| JSON | アプリ名、スキーマ版、履歴ID、UTC保存日時、双方の入力レンジ、ボード、syntax、CSVパス／ラベル、ベットCSV指定、計算設定、基準シード、各条件の詳細結果・頻度を保存。 |
| SVG | 1100×760の散布図。EQと頻度、サイズ別の系列、モンテカルロの95%区間を表示。点のtitleにsyntaxと数値を保存。ブラウザ等で開ける。 |

JSONは本アプリの複数syntax・レンジ対レンジ計算用の形式。添付仕様にある単一ハンド用JSONとは別形式。

## 履歴

EQタブの「EQ履歴」から、保存した結果表・散布図・入力条件を閲覧し、再出力・個別削除できる。「JSONを開く」で書き出した結果も閲覧できる。開いただけで入力フォームの値や現在の計算条件を書き換えない。

既定の保存先：`%LOCALAPPDATA%\FlopCommandApp\History\EQ`。

元のアクションCSVを再読込しないため、CSVが移動・変更・削除されても保存時の結果を確認できる。履歴に元のアクションCSV本体は含まれない。再計算時は元のCSVが必要。手入力・レンジCSVから変換されたレンジは入力テキストとしてJSON内に保持する。履歴は再開可能な計算チェックポイントではない。

破損・未対応版の履歴は一覧から除外して件数を通知する。削除は選択した履歴JSONのみで、元CSVや書き出したファイルを削除しない。

`PLO-Syntax-Lab-Windows-EQ-preview.zip` は、EXE、単独syntax生成HTML、使い方、EQ確認用サンプルCSV、SHA-256一覧を含む。ZIPを展開して `FlopCommandApp.exe` を起動する。
