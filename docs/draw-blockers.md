# フロップのSD・FDブロッカー

通常SDがある手札4枚全体、およびストレート完成ハンドはSDブロッカー分類から除外する。通常FDがある手札全体、およびフラッシュ完成ハンドはFDブロッカー分類から除外する。SDとFDの除外は独立。バックドアのみのハンドは対象。

SD候補はボード以外の物理カード2枚組で、現時点の完成ストレートを除き、次の1枚でストレートになるもの。自分のカードと交差する候補をブロックする。ナッツSD候補は少なくとも1枚のナッツ完成アウツを持つ組。ナッツは候補2枚とボード・完成カードを除いた合法相手2枚組とのストレート高比較で判定し、フラッシュ等は考慮しない。自分の手札による昇格はしない。

FD対象はツートーンの2枚あるスート。自分が同スートちょうど1枚ならブロッカー。ボードの同スートカードを除いた順位でナッツ・セカンド・サード・それ以下を分ける。レインボーのBDFDとモノトーンの完成フラッシュは別概念で対象外。

filter.sd: blocker / blockerNut / blockerNone
filter.fd: blocker / blockerNut / blockerSecond / blockerThird / blockerLow / blockerNone

blockerNoneも自身の同種ドロー・完成役を除外する。FDの対象スートがないボードはblockerNoneも該当なし。既存noneは従来どおり「ドローなし」。新分類はフロップ限定。

既存デフォルトのSD SDblocker / SD !Sdblockerを有効化。各役のFDブロッカーとナッツSDブロッカーを追加。AI用生成recipeでも同じフィルターを使用する。BDSD判定は変更しない。

Engine.blockerDetails(4枚手札) はSD候補数、重複除去したブロック数・率・関与ランクとeligibleを返す。eligible=falseの値はブロッカー分類として使用しない。相手CSVの頻度で重み付けした指標ではない。

ランク別の標準研究ではppを除外しない。再生成・レポートもこの方針を共通化した
[SDランク調査](sd-rank-study.md)を使用する。独自のpp除外syntaxを標準結果へ混ぜない。
