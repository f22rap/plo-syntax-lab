# EQ・ベット頻度の高速化（2026-10-13）

自分のレンジは全入力CSVのweight合計、相手レンジは入力されたweightを使用する。PLOの手札2枚＋ボード3枚、合法な対戦組への重み付け、試行数、乱数系列、信頼区間、ベット頻度の定義は変更していない。

## 変更

- 対戦可能なハンド数の照合を、カード集合の辞書から組合せ番号を使う配列へ変更。1枚・2枚・3枚・4枚の共有カード数を数え、包除原理で衝突しない組数を求める。整数の個数を扱うため、微小weightによる合法ハンドを除外しない。
- 配列は計算準備ごとに約1.12MiB。処理中に自分・相手の照合で再利用し、別ジョブ間では共有しない。
- 各syntaxで抽出した自分のハンド群を、頻度とEQの両方で再利用。重複した抽出を削減。
- キャンセル確認、進捗、対戦不可能なハンドの除外、保存形式を維持。

## 計測

Linux x64 / .NET 8.0.15。同一環境・同一入力、50,000試行、シード7123、3回計測の中央値。Windows .NET Frameworkの実測値ではない。

| 条件 | 変更前 | 変更後 | 速度比 |
| --- | ---: | ---: | ---: |
| フロップ random 対 random、準備＋EQ | 2.070秒 | 0.219秒 | 9.45倍 |
| フロップ AA 対 random、準備＋EQ | 0.535秒 | 0.161秒 | 3.32倍 |
| ターン random 対 random、準備＋EQ | 1.844秒 | 0.197秒 | 9.37倍 |
| ターン AA 対 random、準備＋EQ | 0.484秒 | 0.138秒 | 3.51倍 |
| 全CSV読込＋4条件のEQ・頻度 | 4.871秒 | 1.987秒 | 2.45倍 |

4条件の計測はボード9s8d2d、全ハンド・トップセット・ミドルセット・ボトムセット。各CSVに合法な211,876ハンドを収録し、check 0.4＋bet 0.6を合計。相手はrandom。CSV検証・レンジ展開・syntax抽出・対戦組の準備・4条件×50,000試行・頻度算出を含む。WinForms描画と先行するPowerShell CSV比較の時間は含まない。計測データは合成であり、ユーザーのCSVの実測ではない。

変更前後の24結果（8条件×3回）で、EQ・勝ち・引き分け・負け・抽選回数・合法対戦組数・双方の有効ハンド数が完全一致した。4条件のベット頻度も60%で一致した。

20,827件の回帰チェックが通過。独立した全ペア照合との比較を、フロップ・ターン・リバー、ランダムなレンジ、衝突の多いレンジ、微小weightで追加。全列挙・モンテカルロ・ボード除外・中止・履歴保存の既存検証も通過した。
