# 条件を掛け合わせる

調査条件セットの編集画面で「条件を掛け合わせる」を選択する。既存デフォルト一覧でも、行を選んで「この条件に掛け合わせる」を選択できる。

基本役・FD・pp・BDFD構成枚数を選ぶ。「＋追加条件を表示」でBDFD強さ・本数、キッカー、SD・BDSD、SD/FDブロッカーを表示する。追加項目の未選択は指定なし。「なし」はその特徴を持たないという制約。非表示にした追加項目の選択は保持され、下の条件名に表示される。

項目間はAND、各項目内はOR。「組み合わせ別に登録」にチェックすると直積を最大1,000条件まで生成する。例：pp22/33とBDFD2枚/3枚以上で4条件。未チェックならまとめて1条件になる。

確認用ボードを入力して「このボードでハンド数・syntaxを確認」。Node.jsと同梱のmcp/preview-combination.cjsを使い、各ボードの全合法4枚ハンドに照合する。FDと3枚以上BDFDは計5枚が必要となり成立しない。プレビューは現在の条件の保存前確認であり、全対象ボードの検証の代わりではない。

BDFDはボードに1枚あるスートを手札に2枚以上持つこと。bdPairはちょうど2枚、bdTripleは3枚以上。BDFD2本は別スートで2つのBDFDを持つことで、4枚の手札では2枚+2枚。構成枚数と本数は別々の軸。強さも併用できる。

保存するgeneratorは source=combination, groups=[[preset_id@revision,...],...]。各内側配列はOR、配列間はAND。プリセットの版を保存し、版が合わない場合は黙って新しい意味に変換せずunsupported_recipeとする。additional_syntaxも最後にANDする。既存preset/filterと共存でき、ボードごとに生成・保存・MCP調査できる。旧アプリでは新定義は未対応となるため、EXEとMCPのソースを一緒に更新する。
