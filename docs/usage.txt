PLO Syntax Lab → PowerShell · CSV比較 v11

syntaxの選び方
画面上部のラジオボタンで「デフォルト」「syntax生成」を切り替えます。

デフォルト（起動時の選択）
1. ボードを入力します。Excelや集計用CSVは不要です。
2. 以前の結果CSVに含まれる185件の条件名を使い、現在のボード用のsyntaxを自動生成します。
3. 一覧で条件を選択します。初期選択は Tset all と Mset all です。
4. 集計用CSV1・CSV2（任意でCSV3）を選び、「実行」を押します。

条件名は JsTd7c_frequency_summary.csv のcell・labelを引き継いでいます。
PLO500_JsTd7c_weight_summary.csv の条件名一覧とも一致します。
条件名はアプリに内蔵しているため、これらのCSVを起動時に選択する必要はありません。
過去CSVの固定syntaxを読み込んだり、ランク文字だけ置換したりする方式ではありません。
役・ドローを新仕様で判定し、ボードに合わせて式を生成します。
EdgeまたはChromeを専用の一時環境で裏側の計算に使用します。生成画面を手動で開く必要はありません。
ボードの初回生成には少し時間がかかります。「再生成」で再試行できます。
同じボードの生成結果は起動中に再利用します。

syntax生成
1. 「syntax生成」を選択します。
2. 「syntax生成を開く」を押します。
3. ブラウザで役・FD・SD・BDFD・ポケット・ブロッカー等の条件を選びます。
4. 「比較条件に追加」を押します。
5. 比較アプリへ戻り、CSVを指定して集計します。
保存した条件JSONを「条件JSONを読み込む」で追加することもできます。
生成画面から条件を追加すると、比較アプリは「syntax生成」側へ切り替わります。

切替と選択の保持
同じボードでモードを切り替える間は、各モードの条件一覧とチェック状態を別々に保持します。
両モードの条件を混ぜて集計することはありません。選択中のモードだけを使用します。
モードを切り替えると画面上の古い結果を消去します。保存済み履歴は残ります。
ボードを変更したときはデフォルトを再生成し、個別生成した古いボードの条件は外します。
生成中のボードを変更したりモードを切り替えたりしても、古い生成結果で上書きしません。
起動をまたいだ条件一覧・チェック状態の復元はありません。個別条件はJSON保存できます。

一覧の状態
「選択可」：現在のボードで該当ハンドがある条件です。
「該当なし」：現在のボードでは0コンボなので選択できません。
「対象外」：そのストリートで使わない条件、または新仕様に定義がない条件です。
対象外のセルにマウスを置くと理由を確認できます。
バックドアストレート、SDブロッカー／非SDブロッカー、旧一覧で未定義だったpp allは生成しません。
これらは条件名一覧の行として残し、異なる条件や全ハンドへ置き換えません。
ペアボード等では従来のセット・2ペア・hit条件の多くが該当しなくなります。
フルハウス・トリップス等は「syntax生成」側で選択してください。

計算と保存
・2〜3つのCSVを、条件ごとのweight合計・比率で比較します。
・各CSVの比率 = 各CSVの該当weight合計 ÷ 全CSVの該当weight合計 × 100。
・各CSVにはhandまたはcombo列とweight列が必要です。frequencyで代用しません。
・各CSVのラベルを表・グラフ・結果CSVで使用します。
・「全ハンド（syntaxなし）を集計」は初期状態でオンです。
・合計weightが0の場合の比率は未定義です（画面は —、CSVは空欄）。
・PowerShellのコピー・保存・実行・中止、結果CSV保存は両モードで利用できます。
・入力CSVの重複ハンドやボードカードとの衝突、不正weightはエラーにします。

履歴
正常に完了した結果を自動保存します。「履歴」タブから検索・表／グラフ／コマンドの表示・CSV再保存ができます。
「選択した履歴を削除」で1件ずつ削除できます。元CSVや書き出したCSVは削除しません。
v8〜v10の保存済み履歴は引き続き利用できます。当時のsyntax・数値を書き換えません。
保存先：%LOCALAPPDATA%\FlopCommandApp\History。
失敗・中止した実行は保存しません。単独で実行した.ps1は履歴へ自動登録しません。

動作環境
Windows 10/11、.NET Framework 4.8、Windows PowerShell 5.1、EdgeまたはChrome。
exe単体で使用できます。Excel・Node.jsは不要です。
PLO-Syntax-Lab.html は個別生成画面だけを単独で使うためのファイルです。
PC内で生成・集計し、外部へ公開・送信しません。
MonkerSolver実機での構文受理・抽出一致・文字数制限は未確認です。
